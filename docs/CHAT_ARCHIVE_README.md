# 《家族天下》｜CHAT ARCHIVE README

> 原始 ChatGPT 對話是歷史證據，不是第二套規則來源。

## 原始聊天用途

可用來：
- 查當時到底怎麼說。
- 找遺漏決策。
- 處理版本爭議。
- 保存撤回原因與創意脈絡。

不應直接當：
- 日常規則書。
- Prototype 自動載入規則。
- 新 AI 看到就全部採用的規則。

## GitHub 建議保存

- `CURRENT_RULES_INDEX.md`
- `V04_CURRENT_RULES.md`
- `V04_PROJECT_STATE_YYYY-MM-DD.md`
- `V04_T2_DATA.md`
- `V04_YOUNG_KING_CRISIS.md`
- `OPEN_ISSUES.md`
- 美術規格
- 程式狀態
- AI workflow
- implementation status

## 原始 ChatGPT Export

完整帳號匯出建議放私人硬碟、私人雲端或 Private repo。

如果 `family-empire` 是 Public，不要直接上傳整個 `conversations.json`，因為可能包含其他專案、私人聊天與帳號相關內容。

## 快照版本

建立新 `V04_PROJECT_STATE_YYYY-MM-DD.md` 時：
- 新檔留在 `docs/`。
- 舊檔移到 `docs/archive/`。
- `CURRENT_RULES_INDEX.md` 永遠只指向最新快照。

# 《家族天下》V04｜人物卡草圖規格與內容

> 人物卡美術／UI 規格來源。
>
> 最後更新：2026-10-26
>
> 重要修正：五能力為「武略／治理／王心／交際／名望」；成長指定能力不只可能存在於少年人物。

## 1. 設計目標

人物卡必須同時做到：
1. 一眼辨識人物。
2. 一眼辨識出生家族、性別、年齡階段。
3. 快速讀取五能力。
4. 能承載動態 Token／Tile。
5. 保留足夠插畫面積。
6. 不把尚未定案的狀態硬印成固定欄位。

## 2. 固定印刷資訊【已定】

- 人物姓名
- 測試編號（A1、B4 等；測試期保留）
- 出生家族
- 家徽／家族識別
- 性別
- 當前年齡階段
- 五能力：武略、治理、王心、交際、名望
- 人物插畫
- 若人物資料存在「成長指定能力」，要有最小型固有提示

## 3. 資歷【規則已定；UI未定】

人物有動態資歷1–5，但尚未確認實體表現方式。

可測：小型數字軌＋方塊、小Token、Clip或其他不遮擋插畫的方式。

不得擅自把「印一條資歷軌」標成已定。

## 4. 不設固定印刷欄位【已定】

以下全部使用外加 Token／Tile：
- 在仕
- 退出政治
- 婚姻編號
- 官職
- 爵位
- 危機陣營標記
- 其他臨時狀態

使用者已明確要求：這些東西直接擺在人物卡上，不另外預留專門印刷位置。

## 5. 婚姻標記【已定】

使用成對同號小Token，例如⑦/⑦。一枚放丈夫卡、一枚放妻子卡。

需要多少組尚未鎖定；16組只曾作為候選量，不是正式數字。

## 6. 成長指定能力【已定概念】

它不是第六能力。

若人物資料預先指定未來成長能力，在對應五能力旁加小型固有提示。

可測圖形：小葉芽、細圈、微型枝芽、小星點。

原則：
- 不新增第六欄。
- 不使用額外Token，因為這是人物固有資料。
- 兒童／少年只要資料有指定能力，就應能辨識。

現行例：A5治理、A7王心、B7交際、C7王心、D7武略、D8治理、E5治理、F8名望、G5治理、G6交際。

## 7. 不得自行加入的卡面系統

目前沒有正式決定：
- 雙面人物卡
- 成年A/B面
- 未來成年另一套數值
- NPC／王族／玩家人物固定類型圖示
- 專用官職欄
- 專用爵位欄
- 專用婚姻欄
- 專用在仕欄

## 8. 版面優先順序

不可遮擋：姓名、家族識別、年齡階段、五能力。

次優先：資歷表示、編號、成長提示。

可被Token部分遮擋：插畫背景、插畫下半部、非資訊性留白。

## 9. 建議線框【新提案／可測】

```text
┌──────────────────┐
│ 家徽  人物姓名   年齡/性別 │
│                  │
│      人物插畫     │
│                  │
│ 武  治  王  交  名 │
│ 3   4   2   3   4 │
│       資歷表示      │
│ A4               │
└──────────────────┘
```

Token／Tile 可放插畫下部、左右空白或卡角；不要為Token畫大量永久框。

## 10. 尺寸【待確認】

候選：約70×120mm，或約63×100mm。目前未鎖定。

## 11. 年齡階段視覺

六階段：兒童、少年、成年、壯年①、壯年②、老年。

必須遠看可辨識，不只靠小字。可用小圖示、色帶、邊框節奏或微型符號，但不要破壞家族主色識別。

## 12. 家族識別

至少同時有家徽、家族主色／輔色、服裝語彙、動物物種。避免只靠文字或只靠動物刻板印象。

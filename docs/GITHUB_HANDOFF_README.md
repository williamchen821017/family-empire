# 《家族天下》V04｜GitHub 完整接手說明

> 目標：即使未來整個 ChatGPT Project 消失，只靠 GitHub 也能接手《家族天下》。

## 新接手者先讀什麼

依序：
1. `CURRENT_RULES_INDEX.md`
2. `V04_CURRENT_RULES.md`
3. `V04_PROJECT_STATE_2026-10-26.md`
4. `V04_T2_DATA.md`
5. `V04_YOUNG_KING_CRISIS.md`
6. `OPEN_ISSUES.md`
7. `ART_CHARACTER_CARD_SPEC.md`
8. `ART_VISUAL_BIBLE_STATUS.md`
9. `PROGRAM_STATUS.md`
10. `AI_WORKFLOW.md`
11. `IMPLEMENTATION_STATUS.md`

## 三種真相要分開

規則真相：看 CURRENT_RULES_INDEX、V04_CURRENT_RULES、正式決策。  
工程真相：看 PROGRAM_STATUS、IMPLEMENTATION_STATUS、實際程式碼。  
美術真相：看 ART_CHARACTER_CARD_SPEC、ART_VISUAL_BIBLE_STATUS、實際美術資產。

三者不能混用。

## 不能做的事

- 不得重新設計已定核心。
- 不得把 Prototype 當規則。
- 不得把 AI 模擬當規則。
- 不得把撤回方案復活。
- 不得替版本衝突自行選答案。

## 更新責任

規則變更：更新 `V04_CURRENT_RULES.md`、`OPEN_ISSUES.md`，必要時 `V04_T2_DATA.md`。  
危機變更：更新 `V04_YOUNG_KING_CRISIS.md`。  
人物卡／美術變更：更新 `ART_*`。  
工程同步：更新 `IMPLEMENTATION_STATUS.md`。  
大階段完成：建立新 `V04_PROJECT_STATE_YYYY-MM-DD.md`，更新 `CURRENT_RULES_INDEX.md`。

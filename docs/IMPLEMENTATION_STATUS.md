- GitHub Pages workflow
- `PLAYTEST_NOTES.md`
- Prototype 內建局部測試／紀錄匯出

目前 repo **沒有**：
- package.json
- 獨立 Node.js 遊戲引擎

## 明確仍可保留的 Prototype 價值

即使規則內容落後，以下工程骨架仍有用：
- 2–5 人 Setup UI
- 輪流三輪主要行動的操作殼
- 人物移動與地圖 adjacency 結構
- 判定表與 1D6 / 2D6取高工具
- 官職、家族、產業、人物資料的模組化方式
- 測試紀錄 JSON 匯出概念
- Pages 自動部署

## 同步原則

1. 本文件只記差異，不要求立即把 Prototype 改成最新 V04。
2. 使用者明確要求同步某一塊時，才改該實作。
3. 模擬器不得讀取 Prototype 舊值後宣稱它是正式規則。
4. 每次 Prototype 同步後，刪除或更新對應差異列。
